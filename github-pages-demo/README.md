# GitHub Pages Demo

This project is a tiny static website made to teach how to publish a site on GitHub Pages.

## Files
- `index.html` — homepage structure
- `style.css` — styling
- `script.js` — simple JavaScript

## How to publish it on GitHub Pages
1. Push this project to a GitHub repository.
2. Go to your repository on GitHub.
3. Open the `Settings` tab.
4. Click `Pages` on the left menu.
5. Under "Build and deployment":
   - Source: `Deploy from a branch`
   - Branch: `main` / `master`
   - Folder: `/ (root)`
6. Save.
7. Wait a few minutes, then open your public URL.

Your website will be available at:
`https://<your-username>.github.io/<your-repository-name>/`

Example:
`https://sofianeaddoune55-wq.github.io/sofiane/`

## Why GitHub Pages?
GitHub Pages is a free way to host static websites like:
- portfolios
- landing pages
- demos
- documentation pages

## Learning tip
Start with small static projects like this one before building larger apps with PHP, Node.js, or React.
